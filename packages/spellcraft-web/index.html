Introduction

What is Spellcraft?

Spellcraft is a web component library designed to complement other frameworks without disrupting their functionality. Unlike other frameworks, Spellcraft can be seamlessly integrated into your application without requiring a complete redesign.

At its core, Spellcraft provides JavaScript decorators that empower you to imbue custom elements with functional patterns, enhancing their behavior. This stands in contrast to other frameworks, which mandate inheritance from a singular source for all components. With Spellcraft, prioritizing basic web component standards streamlines the process, allowing you to effortlessly add desired behaviors to your components without being locked into the framework

Installation

Start using


# Using npm 
> npm install @zthun/spellcraft 

# Using yarn 
> yarn add @zthun/spellcraft 
> yarn workspace @org/package add @zthun/Spellcraft
