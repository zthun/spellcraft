Introduction

What is Spellcraft?

Spellcraft is a non-intrusive web component framework that was built with the idea that it can live alongside other web component frameworks and not interfere with their operations. Spellcraft is designed in a way that you can completely rip it out and only lose the functionality that it provides, rather than having to redesign your entire application around

Spellcraft only grants you JavaScript decorators that allow you to decorate a custom element and have it follow a functional pattern for it's behavior. This is in contrast to frameworks such as Lit which require all of your components to inherit from a single source. Instead, all of your inheritance is akin to web component standards and, with Spellcraft, you will simply inherit from the root HTMLElement you need to inherit from. You then decorate it with the behaviors you desire and you're finished.
